# BugSynth

Прототип виртуального синтезатора, в котором каждый инструмент — насекомое, а все ручки вшиты в его тело. Этап 5: пять жуков со звуком настоящих записей, скрещивание (гибрид смешивает записи родителей), бодихоррор-визуал, мобильная вёрстка. Без сборки, без зависимостей.

## Как играть

Синтезатор — сам жук, вокруг нет ни панели, ни подложки. Нажми на тело: звук держится, пока давишь, а тело дёргается в такт ему. Ручки вшиты в тело, тянешь орган вверх-вниз:

- **ПИТЧ** (левая средняя нога): высота записи, ±12 полутонов.
- **СТРЕКОТ** (правая средняя нога): дрожание громкости, от медленного к быстрому.
- **СКОЛЬЖЕНИЕ** (левая задняя нога): высота доезжает до новой не сразу (glide).
- **СКРАБ** (правая задняя нога): запись крутится в коротком окне вокруг «иглы»; ноль — вся запись.
- **РОТ** (голова): фильтр. Закрытый рот глушит звук и добавляет резонанс.
- **НЕОХОТА** (у уса): медленная атака и долгое затухание.
- **ГРЯЗЬ** (спина): искажение; одновременно тело плавно мутирует от чистого к крайней стадии.
- **ВТОРОЙ ЖУК** (левый бок): расстройка, из звука проступают две отстроенные копии.
- **ЭХО** (брюхо): реверберация; брюхо набухает, вокруг тела растёт ореол.
- **ПОВТОР** (хвост): эхо-повтор, повторы темнеют и затухают.
- **ЗАЖИМ** (правый бок): касание включает удержание звука, повторное нажатие на тело гасит звук.

Название органа видно, только пока его тянешь. Органы и значки лотка — картинки, сгенерированные нейросетью (`assets/organs/`), четыре состояния на орган, плавно перетекают по значению ручки; если картинки нет, временная заглушка рисуется кодом. У усача и цикады есть «напряжённая» поза (`assets/bugs/<вид>-<стадия>-strain.webp`): тело перетекает в неё в такт громкости звука. Промпты для картинок: `_референсы/ПРОМПТЫ-v3.md` (вне репозитория).

Внизу маленький лоток: значки жуков (переключение), кнопка скрещивания (BUG-01 × BUG-02, до шести гибридов), × убирает гибридов, i показывает источники. Гибрид смешивает записи родителей и рисуется слиянием по шву; ручки у него те же. На компьютере пробел давит на тело.

## Запуск

```bash
python3 -m http.server 8765
```

Открыть `http://localhost:8765`. С телефона в той же Wi-Fi сети: `http://<IP компьютера>:8765`. Прямое открытие `index.html` двойным кликом не работает: браузер блокирует ES-модули с `file://`.

## Устройство

- `js/genome.js` — гены (значения 0..1), пять жуков (в приложении пока два), скрещивание (`crossGenomes`, `makeHybrid`, `mixSamples`).
- `js/engine.js` — один голос на Web Audio: запись насекомого, синтезированный тон, фильтр, искажение, реверберация, дрожание. Все ручки меняются на ходу. Принимает любой `AudioContext`, в том числе `OfflineAudioContext`.
- `js/hero.js` — тело жука: четыре стадии мутации слоями, слияние гибрида по шву, места на теле для органов.
- `js/organs.js` — органы управления и их рисунок.
- `js/app.js` — сборка: нажатие на тело, дёргание в такт звуку, лоток, сохранение гибридов в `localStorage`.
- `js/bug.js` — прежний процедурный рисунок жука; в приложении сейчас не используется.

## Нарисованные жуки (`assets/bugs/`, `js/hero.js`)

Для усача и цикады есть по четыре картинки-стадии (`clean`, `split`, `fused`, `extreme`), сгенерированные нейросетью по промптам автора и вырезанные скриптом (магентовый фон убран, магентовая подсветка снята). Обычный жук показывается в стадии `clean`. У гибрида стадия растёт с «грузом мутаций» (`mutationLoad`): пороги 0,18 / 0,35 / 0,55. Гибрид двух разных видов показывается слиянием: левая половина от одного родителя, правая от другого, по неровному шву со стежками. У остальных трёх видов картинок пока нет, их рисует прежний процедурный `js/bug.js` (он заметно «милее» и будет заменён).

## Звук: записи насекомых

Звук каждого жука — петля из записи насекомого (`assets/audio/*.wav`, 32 кГц, моно, около 2 МБ всего), сыгранная с разной скоростью по падам, плюс тихий синтезированный тон для высоты. У гибрида записи родителей смешиваются с весами (30–70% на родителя); «груз мутаций» добавляет расстроенную копию записи.

## Гены тела и грязный звук

Кроме 10 звуковых генов есть 8 генов тела: глаза, лишние ноги, нарывы, щупальца, жвалы, асимметрия, мокрость, вскрытость пластин. При скрещивании они мутируют только «в худшую сторону», поэтому каждое поколение гибридов страшнее. «Груз мутаций» (`mutationLoad` в `js/genome.js`) делает звук грязнее: больше шума, расстроенные осцилляторы, второй FM-модулятор, плавающее FM-отношение. У обычных жуков груз около нуля, их звук не меняется.

Диагностика звука: параметр `?fx=` в адресе отключает части цепи (`nocomp`, `noclip`, `notone`, `nolfo`, `nofm`, `nonoise`, `noreso`, `slow`, `nomut`, `nosample`).

## Как работает скрещивание

Для каждого гена: 40% берётся у родителя A, 40% у B, 20% — среднее; затем небольшая случайная мутация (σ = 0,05). Родителем можно выбрать и гибрид.

## Что не проверено

- Как звучат записи на слух: проверены только уровни (пик 0,36–0,52, без NaN). Подбор кусков делал по спектрограммам.
- Все пять жуков рисуются одним шаблоном жука (отличаются гены тела); цикада, сверчок и кузнечик пока выглядят как жуки.
- Из-за смены набора жуков старые гибриды прототипа в браузере не переносятся.
- Звук на реальном телефоне: задержка и громкость динамика. Как звучат гибриды на слух, тоже не проверялось: проверены только уровни (тишины и перегруза нет).
- Соответствие «ген → признак на рисунке» — дизайн-решение, не биология.
- Факт про точильщика (стучит головой по дереву, подзывая партнёра) взят из общих знаний, источник надо сверить.
- Приём для iPhone с беззвучным режимом (`navigator.audioSession` и тихий `<audio>`) написан по общим сведениям, на устройстве не тестировался.
- Биологический факт в карточке (усачи скрипят, потирая переднегрудь о среднегрудь) перед публикацией надо сверить с источником.
