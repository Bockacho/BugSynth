# BugSynth

Прототип виртуального синтезатора, в котором каждый инструмент — жук. Этап 3: два жука, скрещивание, бодихоррор-визуал, звук по тапу, мобильная вёрстка. Без сборки, без зависимостей.

## Запуск

```bash
python3 -m http.server 8765
```

Открыть `http://localhost:8765`. С телефона в той же Wi-Fi сети: `http://<IP компьютера>:8765`. Прямое открытие `index.html` двойным кликом не работает: браузер блокирует ES-модули с `file://`.

## Устройство

- `js/genome.js` — гены (значения 0..1), два жука (`BUG_01` *Cerambyx cerdo*, `BUG_02` *Xestobium rufovillosum*) и скрещивание (`crossGenomes`, `makeHybrid`).
- `js/engine.js` — голос на Web Audio: пила и квадрат, FM, шум, фильтр, «стрекот» (амплитудный LFO), огибающая. Принимает любой `AudioContext`, в том числе `OfflineAudioContext`.
- `js/bug.js` — рисует жука по геному слоями SVG (плоть, бронзовые пластины, ноги, глаза, нарывы, щупальца, проволочный хвост, фильтр мокрого блеска). Каждый из 18 генов отвечает за свой признак (таблица в начале файла), поэтому у гибрида видно наследование. Положения нарывов и глаз берутся из генератора, засеянного геномом: один геном всегда рисуется одинаково.
- `js/app.js` — пады, клавиши A S D F G H J K, октавы, полка жуков, скрещивание, кнопка «Сравнить с родителями», полоски генома с метками родителей. Гибриды (до 12) хранятся в `localStorage` браузера.

## Картинки (`assets/`)

Клавиши (`key.webp`, `key-pressed.webp`), четыре ноги мутантов (`leg1…4.webp`), три фактуры (`tex-flesh`, `tex-bruise`, `tex-bronze`), пятно с глазами, пласт с наростами и пучок щупалец (`eyes`, `growths`, `tendrils`) сгенерированы нейросетью по промптам автора и вырезаны скриптом. Условия коммерческого использования сгенерированных картинок у используемого сервиса нужно проверить до продажи. Исходные листы лежат вне репозитория.

## Гены тела и грязный звук

Кроме 10 звуковых генов есть 8 генов тела: глаза, лишние ноги, нарывы, щупальца, жвалы, асимметрия, мокрость, вскрытость пластин. При скрещивании они мутируют только «в худшую сторону», поэтому каждое поколение гибридов страшнее. «Груз мутаций» (`mutationLoad` в `js/genome.js`) делает звук грязнее: больше шума, расстроенные осцилляторы, второй FM-модулятор, плавающее FM-отношение. У обычных жуков груз около нуля, их звук не меняется.

Диагностика звука: параметр `?fx=` в адресе отключает части цепи (`nocomp`, `noclip`, `notone`, `nolfo`, `nofm`, `nonoise`, `noreso`, `slow`, `nomut`).

## Как работает скрещивание

Для каждого гена: 40% берётся у родителя A, 40% у B, 20% — среднее; затем небольшая случайная мутация (σ = 0,05). Родителем можно выбрать и гибрид.

## Что не проверено

- Звук на реальном телефоне: задержка и громкость динамика. Как звучат гибриды на слух, тоже не проверялось: проверены только уровни (тишины и перегруза нет).
- Соответствие «ген → признак на рисунке» — дизайн-решение, не биология.
- Факт про точильщика (стучит головой по дереву, подзывая партнёра) взят из общих знаний, источник надо сверить.
- Приём для iPhone с беззвучным режимом (`navigator.audioSession` и тихий `<audio>`) написан по общим сведениям, на устройстве не тестировался.
- Биологический факт в карточке (усачи скрипят, потирая переднегрудь о среднегрудь) перед публикацией надо сверить с источником.
